# The Assignment Tracker — setup guide

Setup instructions for the **Gradelink to Notion** Chrome extension, which sends
new Gradelink assignments to your own Notion tracker in one click.

**Read the guide:** https://b-shortandsweet.github.io/gradelink-notion-guide/

**Get the extension:** https://chrome.google.com/webstore/detail/dlfifoaegchgkgbefelekagfndkidapo

**Privacy policy:** https://github.com/b-shortandsweet/gradelink-notion-privacy

This repository exists only to host the guide as a web page. It holds no code
and no personal data.
